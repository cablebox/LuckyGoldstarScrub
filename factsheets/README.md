Files: `meta.txt` (versions, kernel), `privacy.txt` (ACR/ad/telemetry daemons and ACR libraries), `defaults.txt`
(privacy-relevant default settings, including the full `eulaStatus`), `hosts.txt` (LG/ad/analytics hostnames
referenced anywhere), `perf.txt` (preload, memory manager, unit priorities, log levels, kernel config), `qms.txt`,
`hue.txt`, `debug.txt`, and inventories (`bins`, `apps`, `units`, `libs`, `luna_services`, `palm_services`,
`app_sizes`, `big_files`).
